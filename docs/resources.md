# Primary learning references

Reviewed for this curriculum on 2026-10-15. Use your installed version's `go doc` for
precise APIs. The local curriculum uses Go 1.22-compatible APIs; newer docs may show later additions.

- [Go documentation and getting started](https://go.dev/doc/)
- [Tour of Go](https://go.dev/tour/)
- [Language specification](https://go.dev/ref/spec)
- [Effective Go](https://go.dev/doc/effective_go) — useful idioms; supplement with current module/generics docs
- [Standard library](https://pkg.go.dev/std)
- [strings](https://pkg.go.dev/strings), [strconv](https://pkg.go.dev/strconv), [unicode/utf8](https://pkg.go.dev/unicode/utf8)
- [slices](https://pkg.go.dev/slices), [maps](https://pkg.go.dev/maps), [container/heap](https://pkg.go.dev/container/heap), [container/list](https://pkg.go.dev/container/list)
- [encoding/json](https://pkg.go.dev/encoding/json), [encoding/csv](https://pkg.go.dev/encoding/csv)
- [io](https://pkg.go.dev/io), [bufio](https://pkg.go.dev/bufio), [os](https://pkg.go.dev/os), [os/exec](https://pkg.go.dev/os/exec)
- [sync](https://pkg.go.dev/sync), [sync/atomic](https://pkg.go.dev/sync/atomic), [context](https://pkg.go.dev/context), [time](https://pkg.go.dev/time)
- [net](https://pkg.go.dev/net), [net/http](https://pkg.go.dev/net/http), [crypto/tls](https://pkg.go.dev/crypto/tls), [crypto/x509](https://pkg.go.dev/crypto/x509)
- [Memory model](https://go.dev/ref/mem), [race detector](https://go.dev/doc/articles/race_detector)
- [Fuzzing tutorial](https://go.dev/doc/tutorial/fuzz), [diagnostics](https://go.dev/doc/diagnostics)
